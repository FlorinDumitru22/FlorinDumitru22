Stream Integration Guide

YouTube Live Integration

  1. Create a live stream on YouTube Studio
  2. Copy the video ID from the stream URL
  3. Use format: https://www.youtube.com/embed/VIDEO_ID
  4. Paste in Stream URL field above

Twitch Integration

  1. Get your Twitch channel name
  2. Use format: https://player.twitch.tv/?channel=YOUR_CHANNEL&parent=yourdomain.com
  3. Replace YOUR_CHANNEL with your channel name
  4. Replace yourdomain.com with your actual domain

Custom RTMP

For custom streaming servers, provide the embed player URL or iframe code.
